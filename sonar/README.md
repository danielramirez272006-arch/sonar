# 🎵 SONAR · Audiophile Curation Hub & Music Community

Consulta la documentación principal completa del proyecto en el [README raíz](../README.md).

### 🚀 Comandos Rápidos
```bash
# Iniciar API Mock (JSON Server en puerto 3001)
npm run api

# Iniciar Frontend (Vite en puerto 5173)
npm run dev

# Iniciar n8n (Webhooks y Agente Gemini en puerto 5678)
n8n start

# Ejecutar Suite de 157 Tests
npm test
```
