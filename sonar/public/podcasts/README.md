# Directorio de Archivos de Audio de Podcasts — SONAR

Puedes colocar aquí directamente tus archivos de audio para los episodios de Podcast:

### Formatos Soportados:
- `.mp3` (Recomendado, estándar web universal)
- `.wav` (PCM sin comprimir)
- `.m4a` / `.aac` (Audio AAC de alta eficiencia)
- `.ogg` (Vorbis / Opus)

### Cómo utilizarlos en la aplicación:
Si colocas un archivo llamado `episodio-1.mp3` en esta carpeta (`sonar/public/podcasts/episodio-1.mp3`), su URL pública en la aplicación será:
`/podcasts/episodio-1.mp3`

También puedes subir episodios directamente desde la interfaz web en la sección **#podcasts** mediante el botón **«Subir Nuevo Episodio»**.
